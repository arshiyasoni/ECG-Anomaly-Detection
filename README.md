# ECG-Anomaly-Detection
An end-to-end Deep Learning project focused on detecting abnormal patterns in ECG (Electrocardiogram) signals using an LSTM Autoencoder model. The system learns the characteristics of normal heartbeat patterns from time-series ECG data and identifies anomalies by measuring the difference between original and reconstructed signals.

This project uses PyTorch for model development and applies deep learning techniques for analyzing sequential medical data. The workflow includes data preprocessing, model training, reconstruction error analysis, and anomaly detection to identify irregular ECG patterns.

The aim of this project is to demonstrate how Artificial Intelligence and Deep Learning can assist in healthcare applications by automatically analyzing ECG signals and supporting early detection of potential cardiac abnormalities.
